Aquarium Anomaly

Night-shift anomaly-detection horror-lite · Roblox · Pre-production, greenlit for trend-test build

Aquarium Anomaly is a night-shift anomaly-detection horror-lite game set in a dimly lit public aquarium. Each shift, the player patrols a loop of tanks and exhibits, comparing what they see against what should be there — a shark with human teeth, a jellyfish tank that's suddenly bone dry, an octopus pressed against the glass watching them. Spot the wrong thing, report it before the timer runs out, get paid, buy better tools, take harder shifts. It's built for the proven Roblox anomaly-checker audience (the "Animal Hospital (Anomaly)" wave), designed to be cheap to build ($600–$1,000, 2–3 weeks), data-driven so new anomalies cost minutes not days, and engineered for the two things that decide a Roblox game's fate: Day-1 retention and clippable scare moments.

01Design Pillars

"Wait… was that always there?"Every anomaly must create a genuine double-take. Tension comes from uncertainty, not jump scares alone. The player's own memory is the primary game mechanic.
One thumb, 90 seconds to funA brand-new mobile player must understand the game and hit their first anomaly within 90 seconds of spawning. Zero tutorial walls.
Content is data, not buildsAnomalies are rows in a table, not new maps. Adding 10 anomalies post-launch should take under a day. This is the entire economic thesis of the project.
Filmable by designEvery rare anomaly is a potential TikTok. Reveals are staged for a camera: slow burns, glass-tap moments, one "signature creature" people will thumbnail.

02Core Gameplay Loop

Moment-to-moment (the 30-second loop)

  1. Walk to the next tank on the patrol route (tanks are numbered T1–T8 around a single loop corridor).
  2. Observe: compare the tank against its baseline state (learned through play; a "Reference Tablet" tool shows a photo of the normal state for players who buy/earn it).
  3. Decide: normal → move on. Suspicious → open the Report interface.
  4. Report: aim reticle at the tank, tap Report, pick a category from 4 large buttons (Creature / Tank / Environment / Entity).
  5. Resolve: correct report → satisfying "ANOMALY CONTAINED" stinger, cash ping, anomaly reverts or is "escorted out." Wrong report → strike, alarm blares briefly, small pay deduction.

A shift's exact structure

PhaseDurationWhat happens
Clock-in10 sElevator doors open onto the floor. Shift number + modifier shown ("NIGHT 4 — CAMERAS OFFLINE").
Patrol window4–7 min (scales by night)2–6 anomalies are live somewhere on the loop. Timer visible. Anomalies can also spawn mid-shift (a tank fine on your first pass isn't on your second — the core dread engine).
Final sweep warningLast 60 sLights dim further, heartbeat audio layer, timer turns red.
Clock-out15 sResults screen: anomalies found / missed / false reports, pay breakdown, grade (S/A/B/C/F).

Win: report all live anomalies (or enough — see §4) before the timer ends. Lose: 3 strikes in one shift, or miss too many anomalies → "TERMINATED" screen (clippable — the signature creature appears behind the player during the termination cutaway).

Session & meta loops

Session (10–20 min): Play 2–4 shifts → spend earnings in the break-room shop → attempt next night tier → hit a wall or a scare → "one more shift."

Meta (days): Unlock night tiers (1–15+ at launch) → collect the Anomaly Log (a codex page per anomaly ever witnessed — the collection driver) → chase daily bonus shift → cosmetic flashlight/uniform flex in the lobby.

03The Anomaly System

Technical design (data-driven)

Every anomaly is a ModuleScript entry in one table (AnomalyCatalog), consumed by a server-side AnomalyService:

{
  id = "SHARK_TEETH",
  name = "Denture Danger",
  category = "Creature",          -- Creature | Tank | Environment | Entity
  locations = {"T3"},             -- which tank(s) it can occur in
  weight = 10,                    -- spawn weighting within its difficulty band
  minNight = 2,                   -- earliest night it can appear
  difficulty = 2,                 -- 1 easy … 5 brutal
  applyFn = "SwapMeshVariant",    -- named handler: swap mesh/texture/toggle/script
  params = { variant = "SharkHumanTeeth" },
  clipTag = false,                -- true = rare, staged for filming
}
  • Handlers, not bespoke scripts. ~8 generic apply-handlers cover the whole catalogue: SwapMeshVariant, SwapTexture, ToggleVisibility, PlayAnimOverride, MoveModel, LightingOverride, SoundEmit, SpawnEntity. A new anomaly is usually a table row + one variant asset.
  • Spawn table: at shift start, AnomalyService rolls N anomalies (N scales by night), filtered by minNight, weighted by weight, biased so no two share a tank, with a guaranteed difficulty spread. Some slots are flagged delayed — they trigger 60–180 s in.
  • Report mechanic: client raycasts from the reticle to identify the tank zone, fires a RemoteEvent with (tankId, category). Server validates everything: live anomaly present, category match, not already reported. Correct category = +25% pay; correct tank + wrong category still counts as found (forgiving for kids, rewarding for pros).
  • False positives: reporting a clean tank = 1 strike + small deduction + a mocking PA line ("Attention staff: the fish are fine."). Strikes reset each shift — reporting becomes a decision, not spam. Spam-reporting all 8 tanks always loses.
  • Difficulty weighting: each night has a difficulty budget (e.g. Night 6 = 11 points, filled by one 4, one 3, two 2s). Tuned from one config table.

Night tierAnomaliesLengthNew pressure
1–22, diff 1–2, no delayed spawns4 minOnboarding. Near-impossible to miss.
3–53, delayed spawns begin5 minMid-shift spawns; first Entity anomalies; category bonus explained.
6–84, one diff-4 guaranteed6 minModifiers begin (random, one/shift): Cameras Offline, Power Save, Fog Bank.
9–115, active anomalies in pool6 minMiss-tolerance drops to 0.
12–145–6, stacked modifiers7 minThe Curator can manifest on a false report — brief chase-to-elevator (clip fuel, low fail cost).
15+ (Overtime)6, endless rotation7 minPrestige loop: weekly leaderboard of consecutive S-grades.
  • Strikes: 3 false reports = terminated (keep 25% pay). No sanity meter — strikes are simpler and cheaper; the feeling of sanity drain comes free from lighting/audio escalation.
  • Fail forward: failing never de-levels; retry the same night. Failure costs time, not progress — critical for kid retention.
  • Grades: S = all found, all correct categories, no strikes. Gates nothing except the Overtime leaderboard, but S feels prestigious (gold stamp, distinct stinger).

05Economy & Progression

Currency: Credits (₡) — single soft currency, no dual-currency complexity at this scope.

Payouts (per shift, before bonuses): Night 1–2 ₡50 · 3–5 ₡90 · 6–8 ₡140 · 9–11 ₡200 · 12+ ₡275. Bonuses: +25% per correct category, +₡50 S-grade, +₡75 first-clear of a night, daily first-shift ×2.

Pacing math: full tool tree ≈ ₡3,500 ≈ 22–28 shifts ≈ 3–5 sessions of honest play. Grindy enough that the ×2 Credits gamepass is attractive by session two, fair enough that free players finish the tree within a week of casual play.

06Monetization Design

Reality check: at ~26–28% net after Roblox's cut and DevEx, ₨1,000 of player spend ≈ $3.50 to us. A $700 build breaks even at roughly ₨200,000 of gross spend (~$700 net) — on the order of 60k–120k lifetime visits with decent retention. Achievable if the algorithm picks it up, which is exactly what the kill/scale gate (§13) tests.

Ethical guardrails: no loot boxes, no gacha, no FOMO countdowns, no purchase prompts during scares or on the termination screen (Second Chance is offered once, calmly, with an equal-size decline button), all prices visible before confirm, nothing pay-gated that blocks seeing content — paying buys speed and status, never the only path. Right for a kid-heavy audience and pragmatic: predatory patterns are increasingly moderated by Roblox.

07Retention & Virality Hooks

Daily return reasons

  • Daily first-shift ×2 pay + a Daily Anomaly (one hand-picked anomaly guaranteed that day; the community compares notes — "did you find today's?").
  • Login streak: 5-day → exclusive flashlight skin (cosmetic-only, low resentment if broken).
  • Anomaly Log fills only by witnessing anomalies, and rares are rare — a natural long-tail chase.

Virality / clippable design

  • The Curator (signature creature): designed for thumbnails — pale, too-tall figure in a drenched staff uniform, face never fully shown. Appears in exactly 3 staged contexts. Scarcity = clip value.
  • Rare anomalies (#20 Mimic Plaque, #30 Name Tag) use the player's own avatar/username — the most shareable trick in the genre ("IT KNEW MY NAME").
  • 2-player co-op shifts (stretch, §11): friend-drag-in is the cheapest acquisition channel on Roblox; two players disagreeing about a tank is inherently funny content.
  • Update cadence is the marketing: "5 NEW ANOMALIES" badge on the icon every 1–2 weeks — cheap because content is data (§3).

08UI / UX

Screens/HUD (7 total — deliberately minimal):

  1. Lobby/Main menu — elevator hub: Play (big), Shop, Anomaly Log, Settings, gamepass shelf. Other players visible.
  2. Shift HUD — timer (top center), anomalies-found counter ("2/4", shown Night 1–5 for onboarding, hidden Night 6+ for dread), strikes (3 pips), tool belt (2 large corner buttons), reticle.
  3. Report interface — full-screen dim, 4 giant category buttons + Cancel. One tap to open, one to send. No typing, ever.
  4. Results screen — grade stamp, pay breakdown line by line, Next Shift / Lobby.
  5. Shop (break room) — tools tab, cosmetics tab, Robux tab (last, not first).
  6. Anomaly Log — grid of cards, undiscovered = "?" silhouettes.
  7. Settings — volume, camera sensitivity, reduced-flash toggle (photosensitivity — mandatory given flicker anomalies), graphics quality.

Mobile-first controls: default one-thumb movement + auto camera; Report is a single large thumb-zone button that appears only when the reticle is over a tank zone (context-sensitive, no clutter). Interact distance generous (12 studs). Tap targets ≥ 44 pt. PC: E report, F flashlight. Console via ContextActionService.

09Art Direction & Audio

Visual style: low-poly with lighting doing 80% of the work. Flat-shaded models, chunky silhouettes (readable on a 5-inch screen), Future lighting where budget allows / Voxel fallback for low-end mobile. Palette: deep teal-blacks (#0A1A22), tank-glow cyan (#38D6E0), warning amber (#E8A13C) for UI, and one reserved color — anomaly red (#C7303A) — used only for confirmed-anomaly feedback so it stays meaningful.

Key asset list (brutally short): 1 aquarium interior (loop corridor + lobby + break room + security office, ~8 tank alcoves), 8 tank sets with baseline creatures, ~25 anomaly variant meshes/textures (mostly recolors/mesh-swaps — where data-driven design saves the budget), The Curator model, 1 staff uniform + 3 recolors, flashlight/tablet/scanner props. Heavy use of free/marketplace fish meshes retextured — acceptable at this budget, flagged honestly.

Audio is the horror engine (cheapest scare-per-dollar): constant low tank-hum bed, per-zone bubbler loops (whose absence is anomaly #15), muffled whale-song layer, heartbeat at ≤60 s, the "ANOMALY CONTAINED" stinger (must be satisfying — the game's slot-machine ding), three Curator stingers, glass knocks. Sourced from Roblox's licensed library + CC0 to keep cost near zero.

10Technical Architecture

  • Server-authoritative everything that matters: AnomalyService (server) owns the spawn table, live-anomaly state, and validation. Clients never know which anomalies are active — the visual changes replicate, but the truth table lives server-side. Report = RemoteEvent(tankId, category); server validates proximity (≤20 studs), rate-limits (1/s), computes pay. (Determined exploiters can diff rendered state vs cached baselines — accepted risk; payouts are soft currency only.)
  • Data: ProfileService (session-locked DataStore wrapper) for credits, night progress, tools, log, streaks — prevents dupe/rejoin-race exploits. One versioned schema with a migration stub from day one.
  • Structure: single-place game. Shifts are per-player instanced — each player runs their own shift state; the map is shared but anomaly visuals are client-targeted. Avoids reserved-server cost. (Trade-off: two players at the same tank see different things — in this genre that's a feature and a meme.)
  • Performance for mobile: streaming enabled; ≤8k parts in view; anchored everything (near-zero physics); creature swimming via TweenService, not physics; texture atlas per tank; target 30 fps on a 2019-era Android. Voxel lighting fallback via quality detection.
  • Services: DataStoreService (via ProfileService), RemoteEvent/Function (minimal, validated), CollectionService (tank-zone tagging), TweenService, SoundService groups, MarketplaceService (server-side receipt processing + idempotent grant log), AnalyticsService custom events (shift_start, shift_end, report, purchase, night_unlocked).

Secondary diagnostics: tutorial-shift completion (target ≥ 85% — if lower, onboarding is broken, fix first), false-report rate (if > 40%, tells are too subtle), Second Chance attach rate at terminations (validates the frustration-purchase thesis).

The rule, agreed in advance: if after one iteration cycle (one content drop + one onboarding fix, ~2 weeks) D1 is still under 25%, we stop spending. The map and systems get archived for the fishing game (§15) — the project is a $1k option on a trend, not a commitment.

15Reuse for the Fishing Game

This project is partly an R&D purchase for the larger fishing/ocean title. Directly reusable:

  • Creature library: all 8 baseline rigs + swim-tween system → catchable fish, zero rework beyond stat tables.
  • Water/tank visual kit: water materials, caustics rigs, bubbler particles → ocean/harbor environments.
  • AnomalyService architecture: the data-driven catalog + handler pattern generalizes to any content-as-data system — fish species, rare-catch events, weather. The most valuable artifact of the project.
  • ProfileService schema + receipt processing: drop-in economy backbone.
  • The Curator / anomaly IP: a rare "anomalous catch" event ("you caught… something wrong") is a built-in crossover marketing beat between both games' lobbies.
  • Audio bed: underwater ambience library transfers wholesale.
  • Learnings: real data on mobile-horror-lite retention, 79–249 ₨ price performance, and which anomaly categories drive clips — direct input to the fishing game's event design.

Estimated reuse value: 25–35 of the 82 build hours carry forward — even a killed project recovers roughly a third of its cost in the successor's budget.
